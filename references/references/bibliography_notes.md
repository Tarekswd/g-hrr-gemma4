# Bibliography & Literature Notes

1.  **Jimenez et al. (2024)** — *SWE-bench: Can Language Models Resolve Real-World GitHub Issues?* ICLR 2024.
    *   *Significance*: Benchmark foundation for both competition and paper track. Defines test harness, `FAIL_TO_PASS` and `PASS_TO_PASS` criteria.
2.  **Yang et al. (2024)** — *SWE-agent: Agent-Computer Interfaces Enable Automated Software Engineering*. arXiv:2405.15793.
    *   *Significance*: Validates the necessity of structured, constrained agent tools over raw bash commands.
3.  **Zhang et al. (2023)** — *RepoCoder: Iterative Retrieval-Augmented Generation for Repository-Level Code Completion*. arXiv:2303.12570.
    *   *Significance*: Demonstrates iterative retrieval loops outperforming static single-shot retrieval.
4.  **Guo et al. (2021)** — *GraphCodeBERT: Pre-training Language Models with Data Flow*. ICLR 2021.
    *   *Significance*: Theoretical foundation showing that data-flow and AST edge representation improves semantic code understanding.
5.  **Xia et al. (2023)** — *Automated Program Repair in the Era of Large Language Models*. ICSE 2023.
    *   *Significance*: Studies iterative repair loops conditioned on unit test compiler and runtime error outputs.
